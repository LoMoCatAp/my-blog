把下面的地址添加到 RSS 阅读器，之后可以在阅读器里查看新文章：

```
https://lomocat.xyz/feed.xml
```

## 怎么添加

在阅读器里找到添加订阅的入口，粘贴地址，再确认订阅。不同阅读器的按钮名称可能不同。

如果你已经有常用阅读器，继续用它就好。更新多久出现，取决于阅读器检查订阅的间隔。
